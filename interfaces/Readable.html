    subscribe

    • subscribe(fn: Subscriber<T>, options?: SubscribeOptions): Cleanup

      Subscribes to value changes on this source and returns a Cleanup function to unsubscribe.

      By default, delivers the current value immediately (immediate: true) and batches subsequent updates into a microtask (sync: false). Each subscription tracks its own consumed-value baseline and reads the latest value when its turn runs. Call this.dispose() inside fn to unsubscribe from within the callback.

      Parameters

      • fn: Subscriber<T>
      • Optionaloptions: SubscribeOptions

      Returns Cleanup

      Example 

      const count = writable(0);
      const stop = count.subscribe(
        (value) => console.log(value),
        { immediate: false },
      );
      count.set(1); // logs 1 in a microtask
      stop();
