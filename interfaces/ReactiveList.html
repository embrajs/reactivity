    Interface ReactiveList<V>

    A reactive list backed by a plain array. It does not extend Array: indexed access is replaced by get(i) so that reads inside computed or watch are always tracked. Use array for other read-only array operations.

    Ownership tracks values by identity. Removing one of several identical entries reports the value as disposed.
